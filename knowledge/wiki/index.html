CSS / Layoutverified

二次元配置はGrid、間隔はgap

行列の関係を持つレイアウトはGrid、一次元の並びはFlexboxを基本にし、兄弟間の間隔はgapで表現する。

CSS / Accessibilityverified

動きを減らす設定を尊重する

`prefers-reduced-motion: reduce`を使い、利用者OSが動きの抑制を求めているときアニメーションを短縮・停止する。

検証日: 2026-08-27

HTML / Accessibilityconditional

モーダルはdialogの状態管理を使う

`showModal()`でモーダル、`show()`で非モーダルのdialogを開き、ブラウザのtop layer・inert・Esc操作などを活用できる。

検証日: 2026-08-27

HTML / Performanceverified

画像には寸法を持たせる

画像の表示寸法をHTMLで予約すると、読み込み前後のレイアウトシフトを抑えられる。遅延読み込みは初期表示に不要な画像へ限定する。

検証日: 2026-08-27

HTML / Performanceverified

画像候補をpictureとsrcsetで出し分ける

`picture`と`srcset`は、条件に合う画像候補をブラウザへ渡すための仕組み。CSSで隠すだけでは不要な画像取得を防げない。

検証日: 2026-08-27

ページ遷移はa、操作はbutton、開閉はdetails/dialogなど、ブラウザが意味と標準操作を持つ要素を優先する。

検証日: 2026-08-27

JavaScript / Loadingverified

スクリプトの実行境界をHTMLで宣言する

外部classic scriptはdeferでHTML解析後に順序を保って実行でき、module scriptは既定でdefer相当かつ独自スコープになる。

検証日: 2026-08-27

JavaScript / Networkingverified

FetchではHTTP状態を明示確認する

fetchはネットワーク障害ではrejectするが、404や500ではResponseをresolveする。`response.ok`またはstatusを確認してから本文を読む。
